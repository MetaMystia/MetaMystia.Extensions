# SprintControl Changelog

## 1.0.0 - 2026-11-06

### 新增

- 支持 `/sprint <倍率>` 和 `/sprint reset` 实时调整白天加速走时的加速倍率。
- 支持 `0.1～10` 的倍率范围，包括小于 `1` 的倍率。
- 配置自动保存，并在重启游戏后继续生效。
- 联机时通过 MetaMystia 现有运动同步机制传递自定义加速速度。
- 增加游戏 `RELEASE 4.4.0e` 版本门禁。
- MetaMystia 缺失或版本过低时显示本地化安装提示。
- MetaMystia 左下角状态显示已加载扩展数量。
- 增加 `/link MetaMystia.Extensions` 控制台命令。
- 支持简体中文、繁体中文、英文、日文和韩文。
